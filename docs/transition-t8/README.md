# T8 — Production cinematic population

T8 is the content-production pass for the Heart → Wiffeyyyy OS transition.

## Locked production sequence

1. Closed premium Wiffeyyyy OS box.
2. Fully black-gloved hands opening the box.
3. Open box with the phone revealed.
4. Phone lifted and rotated toward portrait.
5. Screen-wake frame.
6. Live handoff frame.

The approved visual language is warm amber studio light, dark stone/table surface, a thin premium lid, seamless black gloves with no visible skin/nails, and a consistent phone/box identity.

## Runtime rule

The final Wiffeyyyy OS screen uses `live-home`, not a baked/generated UI. The generated handoff frame is only a visual bridge; the live phone renders the actual published Home page so wallpaper, widget, app icons, labels and dock stay editable in the backend.

## T8 readiness

A production hybrid sequence is considered complete only when all six desktop frame slots are populated. Mobile frame slots are optional overrides and fall back to desktop frames. Match-cut + wallpaper sync + Live Home is the recommended final handoff.

## Current implementation

The six corrected frames have been prepared for upload/compression and the backend already exposes each scene as an independent Media Library target. T8 adds stricter production-readiness certification so incomplete hybrid sequences are surfaced instead of being mistaken for final output.
