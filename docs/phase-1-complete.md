# Phase 1 — Completion Definition

## Completed
- Responsive public Next.js application
- Separate admin Next.js application
- Shared UI/content packages
- Supabase schema for sites, pages, versions, media, recipient profile and app content
- Draft/published version model
- Admin roles and RLS foundation
- Hierarchical page-document schema
- Editor undo/redo and responsive preview foundation
- Server-side draft save, publish and rollback primitives
- Health endpoints
- CI typecheck workflow

## External activation
Production credentials are intentionally not committed. Activation requires a Supabase project, migration execution, environment variables, authenticated owner, Storage buckets, seed data, Vercel deployment, and production browser verification.
